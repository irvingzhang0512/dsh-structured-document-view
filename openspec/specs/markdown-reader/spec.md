# F003 Markdown 阅读器

## Purpose

为 dsh-structured-document-view 的Markdown 阅读器维护唯一可编辑的行为与验收规格，保留原编号 F003，区分当前预期、尚未实现设计和历史验证；原始需求、项目资料及旧文档继续原位只读保留。

## Requirements

### Requirement: F003 Markdown 阅读器

系统 SHALL 按下列完整场景落实Markdown 阅读器的预期、边界与验收。本节迁入已有功能规则；本次仅迁移文档，没有重新执行产品验收。

#### Scenario: F003-S01 场景与预期

- **WHEN** 用户阅读章节、全文或搜索大纲
- **THEN** 场景与预期：默认大纲＋章节阅读，选节点读取该章节，可切换全文、前后导航、面包屑和搜索；未选择时显示概览。

#### Scenario: F003-S02 边界与异常

- **WHEN** 用户阅读章节、全文或搜索大纲
- **THEN** 边界与异常：章节阅读不继承思维导图的 depth／collapse 截断；大纲搜索包含标题、正文、角色、属性并有数量上限；窄屏大纲用抽屉。

#### Scenario: F003-S03 验收条件

- **WHEN** 用户阅读章节、全文或搜索大纲
- **THEN** 验收条件：正文可完整阅读；切换章节选择同步；全文模式高亮当前节点；搜索可定位，窄屏需 GUI 回归。
