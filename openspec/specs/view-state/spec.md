# F002 视图状态与内容分离

## Purpose

为 dsh-structured-document-view 的视图状态与内容分离维护唯一可编辑的行为与验收规格，保留原编号 F002，区分当前预期、尚未实现设计和历史验证；原始需求、项目资料及旧文档继续原位只读保留。

## Requirements

### Requirement: F002 视图状态与内容分离

系统 SHALL 按下列完整场景落实视图状态与内容分离的预期、边界与验收。本节迁入已有功能规则；本次仅迁移文档，没有重新执行产品验收。

#### Scenario: F002-S01 场景与预期

- **WHEN** 用户改变视图、选择、深度或过滤
- **THEN** 场景与预期：Markdown／思维导图／表格共用文档 id，独立保存视图、选择、展开、深度、布局、过滤和视口状态。

#### Scenario: F002-S02 边界与异常

- **WHEN** 用户改变视图、选择、深度或过滤
- **THEN** 边界与异常：视图操作不改文档正文；各视图深度独立；根深度为 1、0 表示不限，显式展开路径优先；表格不按折叠隐藏行。

#### Scenario: F002-S03 验收条件

- **WHEN** 用户改变视图、选择、深度或过滤
- **THEN** 验收条件：切换视图保留对应设置；设置过滤／深度后文档内容不变；重置只重置视图。
