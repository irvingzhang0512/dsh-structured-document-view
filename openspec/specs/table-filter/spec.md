# F005 表格与过滤

## Purpose

为 dsh-structured-document-view 的表格与过滤维护唯一可编辑的行为与验收规格，保留原编号 F005，区分当前预期、尚未实现设计和历史验证；原始需求、项目资料及旧文档继续原位只读保留。

## Requirements

### Requirement: F005 表格与过滤

系统 SHALL 按下列完整场景落实表格与过滤的预期、边界与验收。本节迁入已有功能规则；本次仅迁移文档，没有重新执行产品验收。

#### Scenario: F005-S01 场景与预期

- **WHEN** 用户查看表格并设置筛选
- **THEN** 场景与预期：表格显示节点角色、属性等投影；角色与属性过滤共同作用，并保留祖先路径，深度限制仍生效。

#### Scenario: F005-S02 边界与异常

- **WHEN** 用户查看表格并设置筛选
- **THEN** 边界与异常：表格只读，折叠状态不隐藏表格行；过滤是视图投影，不删除节点。

#### Scenario: F005-S03 验收条件

- **WHEN** 用户查看表格并设置筛选
- **THEN** 验收条件：筛选同时满足所设条件；祖先可定位；清除筛选恢复数据，IR 不变。
