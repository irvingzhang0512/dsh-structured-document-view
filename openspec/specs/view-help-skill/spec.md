# F008 交互式帮助与中文技能

## Purpose

为 dsh-structured-document-view 的交互式帮助与中文技能维护唯一可编辑的行为与验收规格，保留原编号 F008，区分当前预期、尚未实现设计和历史验证；原始需求、项目资料及旧文档继续原位只读保留。

## Requirements

### Requirement: F008 交互式帮助与中文技能

系统 SHALL 按下列完整场景落实交互式帮助与中文技能的预期、边界与验收。本节迁入已有功能规则；本次仅迁移文档，没有重新执行产品验收。

#### Scenario: F008-S01 场景与预期

- **WHEN** 用户查看帮助或通过中文请求控制视图
- **THEN** 场景与预期：get_view_help 与页面帮助提供可执行的短语示例，中文 Skill 将导航、布局与阅读要求转换为视图工具。

#### Scenario: F008-S02 边界与异常

- **WHEN** 用户查看帮助或通过中文请求控制视图
- **THEN** 边界与异常：帮助不是新的语音识别服务；示例仅操作视图，不能暗示编辑内容或未实现布局。

#### Scenario: F008-S03 验收条件

- **WHEN** 用户查看帮助或通过中文请求控制视图
- **THEN** 验收条件：帮助可在页面打开，示例触发相应视图行为；技能内容可加载。
