# F010 数据源状态机与示例数据边界

## Purpose

为 dsh-structured-document-view 的数据源状态机与示例数据边界维护唯一可编辑的行为与验收规格，保留原编号 F010，区分当前预期、尚未实现设计和历史验证；原始需求、项目资料及旧文档继续原位只读保留。

## Requirements

### Requirement: F010 数据源状态机与示例数据边界

系统 SHALL 按下列完整场景落实数据源状态机与示例数据边界的预期、边界与验收。本节迁入已有功能规则；本次仅迁移文档，没有重新执行产品验收。

#### Scenario: F010-S01 场景与预期

- **WHEN** 客户端初始化、握手、断线或接受宿主能力
- **THEN** 场景与预期：视图数据源显式分三态：`connecting`（未收到 hello-ack）／`host`（宿主声明有文档内核）／`mock`（宿主明确声明无文档内核）。`connecting` 不渲染任何文档内容；`host` 在未绑定时显示空状态；只有 `mock` 才启用内置示例数据，且必须显式标注为示例数据。

#### Scenario: F010-S02 边界与异常

- **WHEN** 客户端初始化、握手、断线或接受宿主能力
- **THEN** 边界与异常：握手前或握手中不得出现任何示例文档标题、大纲或文档切换器；`connecting` 下文档类命令返回 `SOURCE_NOT_READY`，不产生"已打开章节"这类假成功；连接中断保留最近画面与数据源并标注重试中，不得回退为示例数据；`mock` 仅在宿主 hello-ack 明确 `structuredDocument: false` 时进入。

#### Scenario: F010-S03 验收条件

- **WHEN** 客户端初始化、握手、断线或接受宿主能力
- **THEN** 验收条件：
    - A1：新窗口／新会话首帧（握手前）内容区不出现任何文档标题与大纲，显示连接中提示。
    - A2：收到 `structuredDocument: false` 后进入示例模式，页面出现"示例数据"标识，状态栏写明数据源为示例数据。
    - A3：收到 `structuredDocument: true` 且会话未绑定文档时显示空状态，不出现任何示例标题。
    - A4：`connecting` 状态下文档类命令返回 `SOURCE_NOT_READY`。
    - A5：连接断开后画面与数据源保留，界面标注重试中。
    - A6：安装内核且有绑定文档时行为与本变更前一致（回归）。
