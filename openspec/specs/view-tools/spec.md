# F006 17 个视图工具与指代

## Purpose

为 dsh-structured-document-view 的17 个视图工具与指代维护唯一可编辑的行为与验收规格，保留原编号 F006，区分当前预期、尚未实现设计和历史验证；原始需求、项目资料及旧文档继续原位只读保留。

## Requirements

### Requirement: F006 17 个视图工具与指代

系统 SHALL 按下列完整场景落实17 个视图工具与指代的预期、边界与验收。本节迁入已有功能规则；本次仅迁移文档，没有重新执行产品验收。

#### Scenario: F006-S01 场景与预期

- **WHEN** Agent 发起视图工具调用
- **THEN** 场景与预期：工具控制视图、展开／折叠、focus／open、阅读模式与章节、zoom／fit／reset、帮助、深度、布局、过滤、重置及打开视图标签。

#### Scenario: F006-S02 边界与异常

- **WHEN** Agent 发起视图工具调用
- **THEN** 边界与异常：每个工具单一职责；模糊标题多候选需反馈；视图不能调用工具直接改文档结构。

#### Scenario: F006-S03 验收条件

- **WHEN** Agent 发起视图工具调用
- **THEN** 验收条件：17 工具注册；同名引用返回候选；参数错误有结构化反馈；reset 不修改文档。
