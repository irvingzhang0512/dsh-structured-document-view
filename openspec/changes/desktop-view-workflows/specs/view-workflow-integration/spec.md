# F014 三场景视图与原设置回归

## Purpose

为 dsh-structured-document-view 的三场景视图与原设置回归维护唯一可编辑的行为与验收规格，保留原编号 F014，区分当前预期、尚未实现设计和历史验证；原始需求、项目资料及旧文档继续原位只读保留。

## ADDED Requirements

### Requirement: F014 三场景视图与原设置回归

系统 SHALL 按下列完整场景落实三场景视图与原设置回归的预期、边界与验收。本节为原有待实现设计的格式迁移，尚未获得实施批准，不作为现有能力。

#### Scenario: F014-S01 场景与预期

- **WHEN** 用户在思路、会议和项目场景使用视图
- **THEN** 场景与预期：17 工具支持 thinking、会议双稿、project 的阅读／过滤／定位；四项设置继续由 better-sidebar 原 prefs 维护，新 runtime 和 reset_view 使用当前默认。

#### Scenario: F014-S02 边界与异常

- **WHEN** 用户在思路、会议和项目场景使用视图
- **THEN** 边界与异常：表格视图不成为 Excel 编辑器；视图操作不改业务正文；旧值／未知 prefs 保留，不追溯重置已打开会话，关闭卡片不销毁文档内核。

#### Scenario: F014-S03 验收条件

- **WHEN** 用户在思路、会议和项目场景使用视图
- **THEN** 验收条件：三视图／章节／布局／编辑和现有工具回归；同名编号按章节定位；四设置保存／重置与原生入口通过；浅深色、窄栏、键盘、标签销毁检查。
