# dsh-structured-document-view

为结构化文档提供 Markdown、思维导图和表格展示，支持切换视图、定位节点、展开层级与筛选内容。

## 能做什么

- 在三种视图中查看同一份文档，保持节点编号与选中状态对应。
- 按层级、角色和属性筛选内容，聚焦节点、缩放或调整导图布局。
- 通过界面或自然语言切换视图、定位章节、恢复默认展示。
- 文档内容变化后更新视图；视图操作本身不修改业务正文。

## 安装

当前本地版本 **0.4.1**，适配 **DSH Desktop 0.2.1-rc.2**。实际显示页签需要 **Better Sidebar 0.28.0**；查看自己的文档还需 **dsh-structured-document 0.2.1**。这两项在技术上是可选集成，但缺少侧边栏就没有对应展示区域，缺少文档内核只会提供明确标识的示例数据。

截至 2026-10-18，[公开源码仓库](https://github.com/irvingzhang0512/dsh-structured-document-view)默认分支包版本为 **0.2.0**，本页版本尚未公开推送或发布。先向维护者获取当前版本的完整预构建 `.tgz`，目前没有本版公开下载链接。

1. 在「插件」安装并启用上述展示依赖，确认版本匹配。
2. 打开「添加插件 → 安装第三方插件」，填写本插件安装包的本机绝对路径，核对包名和版本后启用，按提示重启 DSH。
3. 进入工作区会话，在侧边栏「＋」菜单打开「结构化文档」；默认也会在会话首次激活时自动打开。

本版三视图与真实隔离文档验证见 [兼容记录](docs/DSH-UPGRADE-20261017.md)。没有将示例显示、工具入队或公网安装记作真实文档验收。

## 配置

默认即可使用。需要改变展示习惯时，在 Better Sidebar 的「设置 → 侧边卡片」找到本插件：

| 设置 | 默认值 | 作用 |
|---|---|---|
| 自动打开视图页签 | 开启 | 会话首次激活时打开页签 |
| 新会话默认视图 | Markdown | 新会话初始展示方式 |
| 新会话默认导图布局 | 逻辑图，向右展开 | 导图初始布局 |
| 新会话导图默认层级 | 2 层 | `0` 表示不限层级 |

设置由 Better Sidebar 保存，用于新会话／新运行时及「恢复默认」，不强行重置已打开会话的当前视图。未设置的字段使用上述默认值。

## 第一次使用

1. 确认安装了文档内核，让 Agent 先列出当前工作区的真实 Markdown 文件，选择一份适合展示的文件。没有文件时，可明确要求新建一份含三个章节的思路整理文档，并核对实际保存路径。
2. 在 Better Sidebar 中打开选定的实际文件，再打开「结构化文档」页签。检查页头显示的是该文件；已使用工作台时以固定整理目标为准。
3. 点击「思维导图视图」，再切到「表格视图」，确认展示的是同一份文档。
4. 对 Agent 说「切成思维导图，只显示两层」，核对视图和层级变化。切换视图后，原 Markdown 正文应保持不变。

## 常用操作

| 想做什么 | 怎么做 | 结果 |
|---|---|---|
| 看整体结构 | 切到思维导图并调整层级 | 显示相应层次的节点 |
| 看任务属性 | 切到表格并按实际角色筛选 | 显示匹配节点及其属性 |
| 阅读某章 | 在大纲选择章节，或让 Agent 定位准确标题 | 聚焦对应章节／节点 |
| 恢复展示 | 点击「恢复默认」 | 使用当前设置中的默认视图、布局和层级 |

## 使用边界

- 连接尚未建立时显示连接状态；有内核但没有绑定文件时显示空态，不用示例冒充真实文档。
- 只有宿主明确没有文档内核时才展示带「示例数据」标识的内置文档。
- 工具可能已注册，但界面尚未连接。已排队不等于已执行，超时也不代表操作没有发生。
- 内容修改属于文档插件；表格视图不是独立电子表格编辑器。
- 更完整的 Desktop 三场景协作仍有待确认／待实现设计，见 [当前规格](docs/SPEC.md)，不属于本版新增承诺。

## 常见问题

### 一直显示连接中，或找不到页签

检查 Better Sidebar、本插件和宿主版本是否匹配且已启用，回到发出指令的会话，从「＋」菜单打开页签。仍无连接时查看插件运行状态，不要反复发送同一视图操作。

### 看到的是示例，不是自己的文件

检查是否安装并启用了文档内核，确认页头的数据来源。内核可用后，打开真实文件或让工作台绑定目标，再核对实际路径。
